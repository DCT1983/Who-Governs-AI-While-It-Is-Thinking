# Who Governs AI While It Is Thinking?

## Persistent Reference Infrastructure and the Economic Wall of Accuracy

**Darren Tindale**  
Independent Researcher  
September 2026

> “Accuracy summarizes performance across prior cases.  
> Residual risk governs the next operation.”

This repository hosts the essay **Who Governs AI While It Is Thinking?**, 
which proposes a runtime-governance architecture for consequential artificial
intelligence systems.

The paper develops several related concepts:

- Persistent Reference Infrastructure
- Reference (baseline) pathway(s)
- Higher-fidelity pathway(s)
- execution-time governance
- continuing authorization
- candidate eligibility
- pre-commitment execution gating
- episode-level governance
- the Economic Wall of Accuracy

The central proposal is that consequential AI should retain a substantive
comparative Reference state while computation is underway, so that changes
in reasoning, evidence, authority, tools, resources, and proposed external
actions can be evaluated before consequential commitment.

catastrophic error less likely to survive unchallenged.**
